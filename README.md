# Telegram Console Bot

Учебный Telegram-бот: получает сообщения через webhook, ищет универсальные OBD-II коды в локальной базе и отвечает пользователю.

## Запуск

Требуется Node.js 20 или новее.

1. Установить зависимости:

   ```powershell
   npm install
   ```

2. Открыть локальный файл `.env` и вставить токен после `TELEGRAM_BOT_TOKEN=`. Этот файл не попадёт в Git.

3. Запустить приложение:

   ```powershell
   npm start
   ```

4. Запустить Cloudflare Quick Tunnel для `http://localhost:3000` и скопировать выданный HTTPS-адрес в `TELEGRAM_WEBHOOK_URL`, добавив путь `/telegram/webhook`.

5. Зарегистрировать webhook:

   ```powershell
   npm run webhook:register
   ```

6. Написать боту `/start` или код вида `P0420`. Бот ответит в Telegram и выведет входящее сообщение в терминал.

Проверка состояния сервиса: `http://localhost:3000/health`.

## Формат кода

Поддерживается буква `P`, `B`, `C` или `U` и четыре цифры: `P0420`, `P0300`, `B0020`, `C0035`, `U0100`.

База содержит только универсальные OBD-II коды. Расшифровка носит справочный характер и не заменяет диагностику автомобиля.
