# Источник базы DTC

`dtc-codes.db` взят из открытого проекта [Wal33D/dtc-database](https://github.com/Wal33D/dtc-database), лицензия MIT.

Скрипт `npm run dtc:build` создаёт `dtc-codes.json` только из записей `GENERIC`. В runtime бот использует JSON, а не SQLite.

Расшифровка кода является справочной информацией и не заменяет диагностику автомобиля.
